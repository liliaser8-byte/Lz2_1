1. Аналіз коду:
   Призначення класів Graphics, Pen, Brush:  Graphics:
   Це основний клас GDI+, який надає поверхню для малювання та методи для відображення ліній, фігур, зображень і тексту на формі або іншому елементі керування.Pen (Перо): Клас, що використовується для малювання ліній та контурів фігур. Він визначає такі властивості, як колір, товщина та стиль пунктиру лінії.Brush (Пензель): Клас, що використовується для заповнення (зафарбовування) внутрішньої області замкнених фігур, таких як прямокутники чи еліпси. На практиці часто використовується SolidBrush для заливки одним суцільним кольором.
   Що виконує команда graf->Clear(Color::White);:  Ця команда повністю очищає графічну поверхню, пов'язану з об'єктом graf, і заливає її білим кольором (Color::White). Зазвичай це робиться перед малюванням нової фігури, щоб стерти попереднє зображення.
   Що означає listBox1->SelectedIndex:  Це властивість елемента списку ListBox, яка повертає цілочисельний індекс поточного виділеного рядка. Нумерація елементів у списку починається з нуля (0 — перший пункт, 1 — другий і так далі). У коді програми це значення використовується в операторі switch, щоб зрозуміти, яку саме фігуру користувач хоче намалювати.

* **Опис роботи:** *
  Ця програма — це базовий графічний застосунок Windows Forms (написаний мовою C++/CLI), призначений для малювання 2D-фігур за допомогою бібліотеки GDI+.

Короткий опис логіки роботи:

Інтерфейс: Програма містить список (ListBox) з переліком доступних фігур (лінія, прямокутник, еліпс, зірка, будиночок тощо) та випадний список (ComboBox) для вибору кольору.

Взаємодія: Коли користувач натискає на назву фігури у списку, генерується подія, яка запускає процес малювання.

Малювання: Програма зчитує обраний колір, очищає робочу область (заливає її білим фоном) і за допомогою оператора switch визначає, яку саме фігуру потрібно намалювати. Після цього використовуються класи Graphics, Pen (для контурів) та Brush (для заливки), щоб зобразити обраний примітив на екрані.

* **Опис роботи:**
  Програма реалізує просту анімацію шляхом послідовної зміни трьох зображень за допомогою таймерів.

* **Запуск:** При натисканні кнопки "Start" встановлюються інтервали для трьох таймерів (500 мс) і запускається перший із них (`timer1`).
* **Цикл анімації:** Робота побудована на взаємодії трьох таймерів через їхні події `Tick`. Коли спрацьовує поточний таймер, він робить видимим одне відповідне зображення у `PictureBox`, приховує два інших, активує наступний таймер у ланцюжку і вимикає сам себе. Таким чином утворюється нескінченний цикл передачі керування: `timer1` → `timer2` → `timer3` → `timer1`.
* **Зупинка:** При натисканні кнопки "Stop" усі таймери зупиняються, а властивість видимості (`Visible`) для всіх трьох зображень встановлюється у значення `false`, приховуючи їх.
