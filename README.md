1. Аналіз коду:
   Призначення класів Graphics, Pen, Brush:  Graphics:
   Це основний клас GDI+, який надає поверхню для малювання та методи для відображення ліній, фігур, зображень і тексту на формі або іншому елементі керування.Pen (Перо): Клас, що використовується для малювання ліній та контурів фігур. Він визначає такі властивості, як колір, товщина та стиль пунктиру лінії.Brush (Пензель): Клас, що використовується для заповнення (зафарбовування) внутрішньої області замкнених фігур, таких як прямокутники чи еліпси. На практиці часто використовується SolidBrush для заливки одним суцільним кольором.Що виконує команда graf->Clear(Color::White);:  Ця команда повністю очищає графічну поверхню, пов'язану з об'єктом graf, і заливає її білим кольором (Color::White). Зазвичай це робиться перед малюванням нової фігури, щоб стерти попереднє зображення.Що означає listBox1->SelectedIndex:  Це властивість елемента списку ListBox, яка повертає цілочисельний індекс поточного виділеного рядка. Нумерація елементів у списку починається з нуля (0 — перший пункт, 1 — другий і так далі). У коді програми це значення використовується в операторі switch, щоб зрозуміти, яку саме фігуру користувач хоче намалювати.
